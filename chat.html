Quantum Polarization & Malus's Law

In quantum mechanics, when a photon in polarized state |ψ⟩ with angle θA is measured using an analyzer oriented at angle θB, the measurement probability obeys Malus's Law:

P(Detect | θA, θB) = |⟨ψB|ψA⟩|2 = cos2(θB - θA)
Matching Bases (Δθ = 0°)

cos2(0°) = 1.0

Deterministic transmission: 100% agreement between Alice and Bob.
Conjugate Bases (Δθ = 45°)

cos2(45°) = 0.50

Pure random coin toss! Maximally uncertain quantum superposition.
Orthogonal State (Δθ = 90°)

cos2(90°) = 0.0

Orthogonal projection: exactly 0% detection probability in that detector.

Law of Total Probability & QBER Derivation

Let M be the event that Alice and Bob choose matching bases: BA = BB. Let E be the event that Eve intercepts the photon, with P(E) = pE. Let Err be the event that Bob's detected bit differs from Alice's bit: Ai ≠ Bi.

Matching Bases: P(M) = 1/2
Eve intercepts: P(E) = pE
BE = BA (prob 1/2)

Eve measures correct basis. State undisturbed.

P(Err | BE=BA) = 0
BE ≠ BA (prob 1/2)

Eve collapses state to wrong basis. Bob gets 50/50 coin flip.

P(Err | BE≠BA) = 1/2
P(Err | E) = (1/2)·0 + (1/2)·(1/2) = 1/4 = 25%
No Eve: P(¬E) = 1 - pE

Channel undisturbed (assuming noiseless fibre).

P(Err | ¬E) = η (channel noise)
P(Err | ¬E) = 0% (ideal)

Total Probability Expansion:

QBER = P(Err | M) = P(E)·P(Err | M, E) + P(¬E)·P(Err | M, ¬E) = pE·(1/4) + (1 - pE)·η

When channel noise η = 0: QBER = pE / 4. If Eve intercepts 100% of photons (pE = 1), QBER = 25%.

Shannon Binary Entropy Function H2(p)

H2(p) = -p log2(p) - (1-p) log2(1-p)

Asymptotic Secret Key Rate R = max(0, 1 - 2H2(Q))

Shor-Preskill Security Bound: Key rate drops to 0 at Q = 11.0%

11.0% Cutoff

Information Theoretic Security & Csiszár-Körner Bound

Alice-Bob Mutual Information I(A; B) = 1 - H2(Q)

Decreases as quantum error rate increases due to noise or eavesdropping.

Alice-Eve Information Leakage I(A; E) ≤ H2(Q)

Under coherent quantum attacks, Eve's bound is constrained by Holevo quantity.

Distillable Secret Key Rate R = I(A; B) - I(A; E) = 1 - 2·H2(Q)

At Q ≈ 11.003%, 2·H2(0.11) ≈ 1.000, so R = 0.

1. Uniform Independent Bernoulli Basis Selection

Alice's basis BA and Bob's basis BB are independent discrete random variables sampled uniformly: P(BA = +) = P(BA = ×) = 1/2 and P(BB = +) = P(BB = ×) = 1/2.

P(BA = BB) = P(+, +) + P(×, ×) = (1/2)·(1/2) + (1/2)·(1/2) = 1/2 = 0.5

2. Sifted Key Length: Binomial Distribution & Central Limit Theorem

For N transmitted photons, the number of matching basis events K is a sum of N independent Bernoulli(1/2) indicators: K = ∑i=1N I{BA,i = BB,i} ~ Binomial(N, 1/2).

E[K] = N/2   |   Var(K) = N/4   |   σ = √N / 2

By the Central Limit Theorem (CLT), as N → ∞, the standardized variable ZN = (K - N/2) / (√N / 2) converges in distribution to standard normal N(0, 1).

3. Strong Law of Large Numbers (SLLN)

The sample average basis match X̄n = (1/n) ∑i=1n Xi converges almost surely (with probability 1) to its expectation:

P( limn→∞ X̄n = 1/2 ) = 1

4. Poisson Statistics for Attenuated Laser Pulses

Practical QKD single-photon sources use heavily attenuated coherent laser pulses. The photon number n per pulse follows a Poisson distribution with mean μ:

P(n photons) = (μn · e-μ) / n!

Multi-photon pulses (n ≥ 2) with probability P(n ≥ 2) = 1 - e-μ - μe-μ enable the Photon Number Splitting (PNS) attack.

5. Vernam One-Time Pad: Shannon Perfect Secrecy

Given plaintext message M and independent uniformly random quantum key K of identical length: Ciphertext C = M ⊕ K achieves Shannon's definition of Perfect Secrecy:

P(M = m | C = c) = P(M = m)   ⇔   H(M | C) = H(M)

Knowledge of the ciphertext reveals zero statistical information about the plaintext.

Why Eavesdropping on Ciphertext Fails:

Because every quantum key bit Ki ~ Bernoulli(0.5) is purely random and independent, for any plaintext bit Pi and any ciphertext bit Ci: P(Ci = 1 | Pi = 0) = P(Ki = 1) = 1/2 and P(Ci = 1 | Pi = 1) = P(Ki = 0) = 1/2. Hence, P(Ci | Pi) = P(Ci), proving statistical independence.
